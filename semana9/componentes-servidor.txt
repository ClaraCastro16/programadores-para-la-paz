Sistema operativo:
Es el software principal que administra los recursos del computador y permite ejecutar aplicaciones. Sirve de base para el funcionamiento del servidor.

Node.js:
Es un entorno de ejecución que permite ejecutar JavaScript fuera del navegador. Se utiliza para desarrollar servidores y aplicaciones web.

Aplicación server.js:
Es el archivo que contiene el código del servidor. Define las rutas y respuestas que recibirán los usuarios.

Puerto:
Es un punto de comunicación utilizado por el servidor para recibir solicitudes. En esta actividad se utiliza el puerto 3000.

Logs:
Son registros de eventos y actividades del servidor. Ayudan a monitorear el funcionamiento y detectar errores.
